# Histoire du Monde

Site web réalisé dans le cadre d'un projet scolaire dans lequel il fallait crée son site ainsi j'ai choisis de réaliser un site portant sur les grandes périodes de l'Histoire.

Le site présente :

- L'Antiquité
- Le Moyen Âge
- La Renaissance
- L'Époque contemporaine

Fonctionnalités :

- Design responsive
- Frise chronologique
- Cartes interactives
- Navigation entre les différentes rubriques
- Pages Sources et Nous rejoindre

Technologies utilisées :

- HTML5
- CSS3

Résultat :

Projet évalué et noté **16/20**.

Points forts relevés lors de l'évaluation :

- Qualité visuelle du site
- Organisation du contenu
- Navigation intuitive
- Mise en page moderne
- Bonne utilisation du HTML et du CSS
